Questions

Is my patients' data kept separate from other clinics?

Yes. Every clinic has its own database. There is no shared patient table.

Do patients need to install an app?

No. Patients use WhatsApp, which they already have. Staff use the web app in any browser.

Which languages does the WhatsApp assistant speak?

English, Hindi, Telugu and Tamil. Each patient's choice is remembered, including for reminders and queue alerts.

Do we need our own WhatsApp number?

Yes — your clinic uses its own WhatsApp Business number, so messages come from your clinic's name. We help you connect it.
